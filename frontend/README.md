This is a React + Vite project for Sunloop Energy.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open the Vite URL shown in the terminal, usually [http://localhost:5173](http://localhost:5173), with your browser to see the result.

You can start editing the app shell in `src/App.jsx` and the page sections in `src/pages/`.

## Learn More

To learn more about React and Vite, take a look at these resources:

- [React Documentation](https://react.dev)
- [Vite Documentation](https://vitejs.dev)

The site is built with Tailwind CSS v4 and React Router.
