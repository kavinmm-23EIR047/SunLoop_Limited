# Sunloop Energy

Production-shaped Next.js App Router marketing site for Sunloop Energy.

## Run locally

```bash
npm install
npm run dev
```

Routes:

- `/` — animated-style flagship home experience
- `/products` — Solar, ESS, EV AC and EV DC product overview
- `/solutions` — residential, commercial, industrial and off-grid segments
- `/ai-portal` — portal feature grid and illustrative dashboard preview
- `/company` — about, mission, vision, values and SDG 7 alignment
- `/contact` — validated contact-form UI and headquarters details

Real contact details are intentionally not fabricated. Add them in `data/content.ts` where marked with `TODO`.

The visuals are self-contained CSS/SVG concepts so real photography and product images can be added later under `public/` without changing the page structure.
